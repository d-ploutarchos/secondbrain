# Bottoms-up plain-English learning prompt

gabriel (@gabriel1) says the greatest prompting hack when you're learning something is still to add this: "explain extremely bottoms up, in plain simple english, in a way that is extremely simple to read once and then you get it. i should have a strong feeling of 'wow i really get it this time' after reading."

**Why it matters:** A short, reusable instruction that pushes the model to teach from first principles in plain language, instead of jumping in mid-stack.

**What to try:** Paste that sentence into a prompt the next time you're trying to actually understand a concept, and see whether the explanation sticks better than a standard ask.
