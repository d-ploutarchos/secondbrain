# Ambition prompt from Anthropic eng lead

Shares a Claude-extracted ambition prompt from Felix Rieseberg's tutorial for Anthropic eng leads. Before building, it asks the model for ALTITUDE (real outcome), DEPTH (top-practitioner bar), RANGE (verbs and outside fields), and VERIFICATION (tests beyond self-judgment), then rewrite the task and wait for go-ahead.

**Why it matters:** A ready system-style prompt to stretch your agent briefs before coding.

**Try it:** Try it: Paste the ALTITUDE/DEPTH/RANGE/VERIFICATION prompt before your next agent task.
