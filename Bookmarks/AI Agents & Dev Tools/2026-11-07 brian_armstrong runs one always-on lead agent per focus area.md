# Brian Armstrong runs one always-on lead agent per focus area

Brian Armstrong now runs one always-on lead agent per focus area plus a chief-of-staff agent overseeing them; each lead manages sub-agents that write code, test, chase reviews. Everything needing his decision lands in one prioritized local web queue with screenshots and demo videos, cleared in batches by voice and keyboard. The system distills his judgment into a 'Brian brain' so drafts need fewer corrections; every change still gets human review and security checks.

**Why it matters:** A concrete, working model of single-queue orchestration for agent teams that cuts context switching.

**What to try:** Build a simple local review queue for your own agents and keep a preferences file the agents learn from.
