# Enable Tailscale Tailnet Lock

Short security tip: if you run Tailscale, turn on Tailnet Lock so new nodes must be cryptographically signed by your own trusted nodes, instead of relying only on Tailscale's coordination servers to decide who joins your network. Widely saved (1,100+ bookmarks).

**Why it matters:** Closes the gap where a compromised or coerced coordination server could add a rogue device to your private network.

**What to try:** If you use Tailscale, read the Tailnet Lock docs and enable it from a couple of trusted devices (keep the disablement secrets safe), then confirm new devices need signing.

Docs: https://tailscale.com/kb/1226/tailnet-lock
