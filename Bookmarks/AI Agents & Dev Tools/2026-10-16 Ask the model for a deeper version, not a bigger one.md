# Ask the model for a deeper version, not a bigger one

Shares Felix Rieseberg's tutorial on being more ambitious with AI models, plus a prompt tweak: ask for a deeper version of the task, have the model say what a top professional would do, which raw material and methods they would use, and what outside check would prove the result right, then rewrite the prompt.

**Why it matters:** A reusable meta-prompt to lift the quality of agent work on big tasks.

**Try it:** Try it: run the deeper-version meta-prompt before your next big agent task.

Felix Rieseberg's tutorial: https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/ (quoted post https://x.com/felixrieseberg/status/2110023283169247623)
