# macOS flag for Computer Use targets

Peter Steinberger shares a defaults command: defaults write -g ComputerUseAllowForbiddenTargets -bool YES.

**Why it matters:** Unlocks more apps for computer-use agents on Mac.

**Try it:** Try it: run the defaults command to allow restricted computer-use targets.
