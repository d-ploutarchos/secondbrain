# Headroom compresses tokens before the LLM

Open-source Headroom by a Netflix engineer sits between agent and LLM and compresses JSON, code, logs and RAG chunks, e.g. so a 10,000-token log costs closer to the 1,200 needed.

**Why it matters:** Could cut your token bills.

**Try it:** Try it: put Headroom in front of your agent's model calls.
