# Debloat a smart TV with Claude Code over adb

Following @doooyle's post about hacking his TV with Claude Code, Romain confirms it is easy: Claude runs adb commands over the local network. He disabled Xiaomi's analytics packages to free 131 MB of RAM and shares the full prompt: back up the package list, sort likely bloat, disable with pm disable-user, revert with pm enable.

**Why it matters:** A cheap, reversible home hack that shows how far a coding agent can reach on everyday devices.

**Try it:** Try it: give Claude Code the adb debloat prompt and clean up your smart TV.
