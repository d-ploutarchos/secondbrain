# Antigravity / Google support in Nanocode

Georgios Konstantopoulos (@gakonst) reminds that he added Antigravity / Google model support to [Nanocode](https://github.com/nanocodexyz/nanocode), so you can use those models from the CLI or as a library without going through a redacted provider. `nc setup google` walks through Google's auth (subscriptions work too). You get the same tools and prompts they use, plus code mode. Install from source at the repo above, or with the installer he posted (`curl https://nanocode.paradigm.xyz | sh`; the page is https://nanocode.paradigm.xyz). This is a follow-up to his earlier announcement in the swarm-riding thread.

**Why it matters:** A practical way to run Google / Antigravity models inside the same Nanocode harness he describes in the swarm-riding essay, including auth.

**What to try:** If you want to try Nanocode or Google models in a CLI harness, install it and run `nc setup google`.
