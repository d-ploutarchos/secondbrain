# insomnia keeps agents running with lid closed

Open-source tool described as caffeinate for agents. Keeps agents running with the MacBook lid closed, pauses unneeded apps and switches to your phone hotspot when you leave Wi-Fi.

**Why it matters:** Could keep your local coding agents running while you're on the move.

**Try it:** Try it: install insomnia to keep Mac agents alive with the lid shut.
