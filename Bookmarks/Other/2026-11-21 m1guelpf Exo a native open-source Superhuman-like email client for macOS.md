# Exo, a native open-source Superhuman-like email client for macOS

Miguel Piedrafita (@m1guelpf) launched [Exo](https://github.com/m1guelpf/Exo), a fast, local, native Gmail client for macOS inspired by Superhuman. It is written in pure Rust with no Electron or webviews, needs no third-party servers, and is free and open source.

**Why it matters:** A serious, local alternative to Superhuman-style mail on a Mac, without a hosted middleware layer.

**What to try:** If you want a faster native Gmail client on macOS, try Exo from the GitHub repo.
